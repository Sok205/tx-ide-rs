Runs f on ext[plugin] (Null when absent) under the session lock and saves the record if the value changed; leaving it Null removes the key. Returns whether a write happened. f must not call back into the core (the lock is held).

pub fn refresh_all(&self) -> Result<Vec<Session>, CoreError>

One list-sessions for every record; returns the records that changed. Records are scanned before tmux is listed: a record exists only after its tmux session does, so a record missing from a later listing has truly gone (the other order would mark a session created between the two calls as exited).

pub fn forget_session(&self, id: &SessionId) -> Result<bool, CoreError>

Deletes the record (and its profile file). The tmux session, if any, keeps running and is no longer managed. Ok(false) when there was no record.
