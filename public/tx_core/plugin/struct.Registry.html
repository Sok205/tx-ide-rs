pub fn resource( &mut self, name: &'static str, bytes: &'static [u8], ) -> Result<(), PluginError>

Publishes a named static blob; the core stores and lists it, never reads it. name is [A-Za-z0-9_./-]+, no leading /, no .. segment, unique across plugins. Convention: <kind>/<file>, e.g. keys/kill.tmux.
