# poc phase 1 — `views` plugin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The session keys of the tx-ide tmux fragment (prefix+t picker, prefix+e edit, prefix+X kill, prefix+s relabel, the nav keys, the pane-border label) work against `txc` and the core's private tmux server.

**Architecture:** One new plugin crate `poc/plugins/views` (`tx-views`, id `views`) with three modules: `tmux.rs` (the UI tmux helper, every call bound to the core socket), `render.rs` (picker rows), `editor.rs` (the modal form), plus one verb struct per verb. The core gains one generic helper, `Session::ext`. The IDE runs *on the core server*: the user's terminal attaches to `<state_dir>/tmux.sock`, whose `tmux.conf` sources a poc copy of the tmux fragment; nesting (a picker attach inside a pane) stays on that one server exactly as main nests on the default server. Scripts find the binary through the server option `@tx-bin`.

**Tech Stack:** Rust 2024, tx-core, serde_json, libc (raw mode), tmux 3.5, fzf 0.72.

**Spec:** `docs/superpowers/plans/2026-10-19-poc-port-roadmap.md` (phase 1, D1–D7), `docs/superpowers/specs/2026-10-16-poc-plugins-design.md` (the host). Source of the ported behaviour: `crates/tx/src/verbs/listing.rs`, `render.rs`, `session_editor.rs`, `verbs/sessions.rs`, `tmux.rs`, `bin/tmux-*`, `tmux/tx-ide.tmux` on `main`.

## Global Constraints

- All work in `poc/`; `cd poc && cargo test --workspace && cargo clippy --workspace --all-targets -- -D warnings` green after every task.
- Every tmux call from the plugin is `tmux -S <core.socket_path()> -f <core.config().tmux_conf_path()> …`; never bare `tmux`.
- Verb names keep main's spelling except where `RESERVED` in `tx-core-cli/src/plugins.rs` forbids: the picker is `pick` (main: `attach`).
- Session option names follow the core's hyphenated `@tx-id`: `@tx-view`, `@tx-name`, `@tx-label-rev`, `@tx-bin`.
- Hidden verbs start with `_`. Usage errors exit 2 with the usage line on stderr; a missing session exits 1 with `session '<token>' not found`.
- No new core types beyond `Session::ext`. Plugin state is `ext["views"]` only; no data dir in this phase.
- Ported format strings are byte-identical to main's (`render.rs:136-140`, `listing.rs:614-685`, `session_editor.rs` hints). Where main's record has a field the poc lacks (state, role, group, last_activity), this plan names the substitute.

## Review Focus

1. A record with `ext["hooks"]` or `ext["views"]` that is not an object (hand edit) must still produce a picker row and a `_pane-label` (Task 4, Task 6: tests with `"ext":{"hooks":5}`).
2. A session whose tmux session vanished between `refresh_all` and `list-sessions` must not break `_list`: rows come from records, targets from one `list-sessions`; a missing target leaves field 4 empty and the picker falls back to the name (Task 4).
3. `_edit-session` renaming to a name another running session holds must leave the record unchanged and show the core's error on the status line, exit 1 (Task 7).
4. `kill` on a view home (a tmux session carrying `@tx-view` with no record) kills it and exits 0; on an unknown token it exits 1 (Task 5).
5. `pick` run outside the core server (`$TMUX` empty or another socket) must still work: Enter does `attach` with `TMUX` removed and `-S` set, never `switch-client` (Task 4).

**Interfaces (verbs):**
- `kill <token>` — `core.resolve` → `core.stop_session` → stdout `Killed '{name}'`. If `resolve` fails and `ui.has_session(token) && ui.is_view(token)` → `ui.kill_session(token)`, stdout `Killed '{token}'`. Else stderr `session '{token}' not found`, exit 1.

- `_relabel` — for every Running record present in `live_targets`: `set-option -t ={name}: @tx-name "{name}[ [t1,t2]]"`. Silent, exit 0.
- `whoami` — not `ui.inside()` → stderr `txc whoami: not inside the tx tmux server`, exit 1. Else `#S` → resolve → print the record name, else the raw `#S`.
- `_pane-label <pane_id> [rev]` — port of `bin/tmux-pane-session-name`: `ui.pane_option(pane, "@remote-session")` → `(r) {name}`; else `ui.inner_for_pane(pane)` → resolve by name → `#[bold]{name}#[default]` + per tag ` #[fg={tag_hex},#{?pane_active,bold,nobold}][{tag}]#[default]`; nothing nested → `#[fg=colour240,nobold]—#[default]`.
