The snapshot every read returns. Disk is the record; tmux holds only the @tx-id link.
SessionId
A record id: a uuid v4 minted by create_session. Every way to build one validates the grammar [A-Za-z0-9_-]{1,64} (parsing, deserializing), so an id is always a safe file-name fragment and tmux option value: <id>.json, <id>.lock, @tx-id.
